# solar-challenge-week1

This repository contains the code and analysis for the solar challenge.

## Environment Setup

To reproduce the development environment, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/your-username/solar-challenge-week1.git](https://github.com/your-username/solar-challenge-week1.git)
   cd solar-challenge-week1
2. Create and activate the Python virtual environment (using venv):
   python3 -m venv .venv
   source .venv/bin/activate  # macOS/Linux
   # .\.venv\Scripts\Activate.ps1  # Windows PowerShell
3. 
pip install -r requirements.txt
